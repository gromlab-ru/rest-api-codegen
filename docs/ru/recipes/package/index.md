# Пакет

Отдельный пакет удобен, когда один API используют несколько приложений. Его можно хранить в монорепозитории или публиковать в npm-реестр.

## Выберите вариант

| Вариант | Когда подходит |
| --- | --- |
| [Пакет в монорепозитории](./monorepo-package.md) | Все приложения находятся в одном репозитории |
| [Отдельный npm-пакет](./npm-package.md) | Клиент нужен приложениям из разных репозиториев |

Если клиент нужен только одному приложению, проще генерировать его прямо внутри [React + Vite](../react-vite/full-client.md) или [Next.js](../nextjs/full-client.md) проекта.

## Основные правила

- Сгенерированные файлы не редактируются вручную.
- Перед сборкой каталог `dist` очищается.
- Поле `exports` задаёт поддерживаемые пути импорта.
- `sideEffects: false` используется только в пакете без побочных эффектов при импорте.
- Временные исправления удаляются после обновления OpenAPI и выпуска новой версии.

Примеры подключения пакета к приложению находятся в разделах [React + Vite](../react-vite/index.md) и [Next.js](../nextjs/index.md).
