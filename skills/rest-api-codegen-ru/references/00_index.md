# Документация `rest-api-codegen`

`rest-api-codegen` помогает создавать типизированные TypeScript-клиенты REST API автоматически из OpenAPI либо вручную на общих runtime primitives.

Работа с API состоит из двух независимых решений:

1. Выбрать сценарий, то есть источник типов и operations.
2. Выбрать способ использования operations для конкретного consumer.

## Порядок чтения

1. Всем пользователям: [обзор](./01_overview.md), [соглашения по именованию](./02_naming-conventions.md), затем [быстрый старт](./03_getting-started.md).
2. Для автоматического сценария: [CLI](./04_cli.md), затем [состав generated SDK](./05_generated-sdk.md).
3. Для ручного сценария: [ручное создание API-клиента](./06_manual-client.md).
4. Для временного исправления generated SDK: [смешанный сценарий](./07_custom-operations.md).
5. После выбора сценария: [композиция API-клиента](./08_client-composition.md), [`HttpClient`](./09_http-client.md) и [правила проектирования REST-клиента](./10_rest-client-engineering.md).

Готовые прикладные решения собраны отдельно в каталоге [рецептов](./recipes/index.md). Номера задают порядок и группировку материалов, но не требуют читать нерелевантные сценарии.

## Выберите сценарий

| Состояние API contract | Подходящий сценарий |
| --- | --- |
| Есть актуальная OpenAPI | [Автоматический: generated SDK](./05_generated-sdk.md) |
| OpenAPI пока нет | [Ручной API-клиент](./06_manual-client.md) |
| SDK генерируется, но отдельная operation неверна и спецификацию пока нельзя исправить | [Временный смешанный сценарий](./07_custom-operations.md) |

Автоматический сценарий является естественным выбором, когда OpenAPI служит источником истины. Ручной позволяет не ждать появления спецификации. Смешанный нужен как временное исключение и завершается возвратом к generated operation.

Подробная схема выбора и матрица сочетаний приведены в [обзоре проекта](./01_overview.md).

## Выберите способ использования

| Потребность текущего consumer | Подходящий способ |
| --- | --- |
| Нужен весь или почти весь API | Полный API-клиент |
| Домену нужна связанная группа operations | Частичный API-клиент |
| Hook, fetcher или небольшой adapter использует один endpoint | Точечная operation |

Это не глобальный выбор для всего приложения. Полный общий клиент, несколько частичных доменных клиентов и точечные вызовы могут одновременно использовать один configured `HttpClient`.

Примеры и компромиссы: [композиция API-клиента](./08_client-composition.md).
