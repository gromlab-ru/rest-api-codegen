# React + Vite

В этом разделе API-клиент работает в браузере. Адрес сервера, авторизация и обработка ошибок настраиваются один раз в `HttpClient`.

## Подключить API

- [Полный клиент](./full-client.md) - установка, генерация и первый `POST`-запрос.
- [Частичный клиент](./partial-client.md) - только методы, нужные конкретному разделу приложения.
- [Ручной клиент без OpenAPI](./manual-client.md) - типы и запросы описываются в приложении.
- [Исправление неверно описанного метода](./broken-endpoints.md) - временная замена одного сгенерированного запроса.

## Работать с серверными данными

- [TanStack Query](./tanstack-query.md) - получение, отправка и обновление кеша.
- [SWR](./swr.md) - получение и отправка данных через отдельные операции.

## Настроить авторизацию

- [JWT из `localStorage`](./jwt-local-storage.md).
- [Cookie-аутентификация](./cookie-auth.md).
- [Обновление токена доступа](./refresh-token.md).

## Обработать частые случаи

- [Ошибки, повтор запросов и отмена](./errors-retry-cancellation.md).
- [Загрузка файлов и ответы не в JSON](./file-upload.md).

## Что выбрать

| Потребность | Решение |
| --- | --- |
| Нужна большая часть API | [Полный клиент](./full-client.md) |
| Разделу приложения нужно несколько методов | [Частичный клиент](./partial-client.md) |
| Хук вызывает один метод | [TanStack Query](./tanstack-query.md) или [SWR](./swr.md) |

Если клиент нужно распространять отдельно от приложения, используйте раздел [Пакет](../package/index.md).
